# Wyl Creature Combat Comprehensive Rules

1.  Each creature can have abilities.
    1.  An ability with a trigger is a “triggerable ability”.
    2.  Abilities can be activated
        1.  A player must first pay the ability’s cost, if any, to activate it
            1.  All parts of the cost must be paid
        2.  A player may manually activate a friendly creature’s ability on their turn.
            1.  Activating an ability manually starts a moment.
            2.  Triggerable abilities can be manually activated.
                1.  Manually activated abilities don’t have an arriving or triggering creature to select. They can still be manually activated but effects that require an arriving or triggering creature don’t do anything.
        3.  A triggerable ability may be activated when a triggering event happens.
            1.  Activating a triggerable ability is called “triggering” it.
            2.  A “trigger” (triggering event) can be another ability, an action, or the start of a moment.
                1.  Only triggering events listed on the ability can be used to trigger it.
            3.  Triggering an ability is optional.
            4.  If an ability has more than one trigger, you may activate it when at least one of its triggering event happens.
            5.  Any player may trigger an ability when a trigger happens.
        4.  When an ability is activated, it gets put into the queue.
            1.  Requirements are not checked before the ability gets put in the queue.
            2.  If there is no queue, a moment is started, and the ability goes in the new moment’s queue.
        5.  The queue processes an ability.
            1.  The queue checks the requirements of the ability, if any.
                1.  If all the requirements are met, then the queue resolves the ability.
                2.  If at least one of the requirements are not met, then the queue cancels the ability and does not resolve it.
    3.  Some keywords are entire abilities
        1.  If it has a trigger, it can only be activated when its trigger happens.
    4.  Abilities can only select creatures in the same zone.
        1.  Each player’s hand counts as part of the landmark zone.
        2.  An ability can only select a creature at the landmark, unless stated otherwise
            1.  An ability cannot select a creature in a player’s hand, unless stated otherwise
2.  Moments
    1.  Moments can only be started in the landmark zone.
    2.  Abilities can only be triggered during a moment.
    3.  Abilities can only make a moment in the landmark zone.
    4.  Abilities that effect the Rest zone can only be activated when the creature is in the Rest zone.
    5.  A moment is created when:
        1.  A battle begins
        2.  A player takes the first action on their turn
        3.  A battle resolves
        4.  A battle ends
3.  Battles
    1.  When a battle ends:
        1.  Each creature in the landmark zone increases its Rest value by its Rest cost.
            1.  If a creature’s Damage value is greater than its Rest cost, then increase its Rest value by the difference, so the total increase in Rest value is equal to the Damage value.
        2.  Each creature with a Rest value greater than 0 moves to their Rest zone.
        3.  Each creature in a Rest zone decreases their Rest value by 1.
        4.  Each creature with a Rest value of 0 or less moves to their army.
